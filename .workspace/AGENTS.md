# How to make prezentation
In this project, you will create presentation content.
The presentation utilizes a custom theme model for the marp engine called tmu-cs (https://github.com/taishi-n/marp-theme-tmu-cs). The core theme files are located in ~src/marp-theme-tmu-cs. For detailed usage instructions, please refer to the AGENTS.md file within that directory.
You will create presentation content based on user specifications.
Additionally, as needed, create supporting files (such as code files or bibliography files) and incorporate them into your presentation.
